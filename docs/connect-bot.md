# Подключение Telegram-бота

## Получение токена

1. Откройте официальный бот `@BotFather` в Telegram.
2. Создайте нового бота или выберите существующего.
3. Получите Bot API token.
4. Никому не отправляйте токен и не добавляйте его в исходный код.

Если токен был опубликован или передан постороннему, отзовите его через BotFather и создайте новый.

## Добавление в приложение

1. Запустите Native Bot Create.
2. Нажмите добавление бота.
3. Вставьте Bot API token.
4. Дождитесь проверки через Telegram `getMe`.
5. Выберите способ получения событий: webhooks или long polling.
6. Для webhooks откройте настройки бота и укажите HTTPS-адрес подготовленного сервера. Для long polling домен и SSL не нужны.
7. Запустите бота.

После запуска `NativeBot.Agent` регистрирует отдельный webhook либо удаляет прежний webhook и начинает long polling. Настройка каждого бота независима. Для webhook сервер должен быть подготовлен по инструкции [Подготовка пользовательского сервера](server-setup.md).
